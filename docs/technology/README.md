## Scope

These guides describe the automatic OKEY mechanism and features covered by the supplied product technical information. Confirm the mechanism, controller and tile configuration for the selected standard or foldable model. The content does not automatically apply to Mahjong tables or every model listed in the product catalog.

The measurement guide identifies each component or action and preserves the qualifications attached to the reported R&D figures. For a purchase specification, confirm model applicability and the relevant test conditions with INEAN PLAY.

Use the [current user manuals](../../manuals/text/README.md) for operating, safety and maintenance procedures. These technical explanations supplement those instructions.
